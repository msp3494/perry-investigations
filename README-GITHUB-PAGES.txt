GITHUB PAGES — SIMPLE DEPLOYMENT
1. Create a new public GitHub repository (example: perry-advisory-investigations).
2. Upload ALL files and the assets folder from this package to the repository root.
3. In GitHub, open Settings > Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Select branch "main" and folder "/ (root)", then Save.
6. GitHub will provide a temporary URL. Test every page there before connecting a custom domain.
7. When ready for your domain, enter perryinvestigationsllc.com in Settings > Pages > Custom domain.
8. Follow the DNS instructions shown by GitHub at your domain registrar.
9. After DNS is verified, enable "Enforce HTTPS".
